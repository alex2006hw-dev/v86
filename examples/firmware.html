Built-in firmware — browser boot test

Boots a BIOS self-test boot sector, assembled in the page, on the built-in firmware (MIT) so no ROM image is needed. The same sector can be booted against SeaBIOS and the Bochs BIOS from bios/, which is what the pre-firmware examples did. The reference BIOSes must run with the JIT off (TechDebt JIT-1); the built-in firmware runs with it on. See examples/firmware.html source and docs/architecture.md.
